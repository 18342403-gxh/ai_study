# 评测集（spec 4.11）

个人记忆系统问答质量的回归门禁。**每次修改 prompt 或检索参数后必须跑一遍**（spec 4.11.3）。

## 运行

```bash
cd apps/server
pnpm eval                 # 全量 20 条（真实 LLM，需要 AI_API_KEY）
pnpm eval -- --no-judge   # 跳过 LLM 裁判（幻觉率/引用准确率按满分处理）
pnpm eval -- --only=time  # 按 id 前缀过滤：time / plan / fact / miss / conflict / degraded
```

评测在独立临时 SQLite（`%TEMP%/kb-eval-<pid>.db`）中跑，不碰开发库；每个用例用独立 `libraryId` 隔离种子数据。

## 指标与门禁

| 指标         | 口径                                 | 门禁  |
| ------------ | ------------------------------------ | ----- |
| 命中率       | 期望引用的条目全部出现在引用列表     | ≥ 80% |
| 引用准确率   | LLM 裁判：回答与来源记录无出入       | ≥ 80% |
| 幻觉率       | LLM 裁判：出现来源没有的个人事实断言 | **0** |
| 无命中识别率 | 无记录用例：零引用且明确说"没有"     | 100%  |

任一不达标进程退出码为 1，可挂 CI。

## 用例结构（cases.json）

- 时间查询 5（明天/今天/本周/绝对日期/重复事件窗口展开）
- 规划状态 4（进展/目标/多计划/计划与日程区分）
- 事实偏好 4（技术栈/作息/饮食/居住地）
- 无命中 3（零记录提问，必须说"没有"且不引用）
- 时间冲突 2（同时段两条日程都要被引用；重复事件与单次事件叠加）
- 降级 2（`ENABLE_MOCK_EMBEDDING=1` 下 BM25/时间通道仍须命中）

种子时间一律用相对偏移（`offsetDays` / `weekday`），用例永不过期；查询里的
`{{d:N}}`、`{{wd:W}}` 占位符由 runner 展开成「M月D日」。

新增用例时同步更新本文件的分类计数。
