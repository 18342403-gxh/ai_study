# 模块 6：RAG 前端集成

## 学习目标

- 理解 RAG（检索增强生成）的原理
- 实现文档上传和处理的前端交互
- 展示检索结果和引用来源
- 构建知识库问答界面

## 知识点

### 6.1 RAG 基本原理

```
用户提问 → 向量检索相关文档片段 → 将片段作为上下文注入 Prompt → 模型基于上下文回答
```

RAG 解决的问题：
- 模型知识有截止日期
- 模型不了解私有数据
- 减少幻觉（有据可查）

### 6.2 前端在 RAG 中的角色

前端主要负责：
1. **文档上传**：文件选择、上传进度、格式校验
2. **问答交互**：提问 + 展示回答
3. **引用展示**：显示回答引用了哪些文档片段
4. **知识库管理**：文档列表、删除、状态查看

后端负责：
- 文档解析（PDF/Word/Markdown → 文本）
- 文本分块（Chunking）
- 向量化（Embedding）
- 向量存储和检索

### 6.3 引用展示设计

```typescript
interface Citation {
  documentName: string   // 来源文档名
  pageNumber?: number    // 页码
  content: string        // 引用的原文片段
  relevanceScore: number // 相关度分数
}
```

展示方式：
- 回答中标注引用编号 [1] [2]
- 底部展示引用详情
- 点击可跳转/高亮原文

### 6.4 文档处理状态

```
上传 → 解析中 → 分块中 → 向量化中 → 就绪
```

前端需要展示每个阶段的进度。
