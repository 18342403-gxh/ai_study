# 🤖 前端 AI 应用开发 — 学习计划

## 总览

本学习计划从前端工程师的视角出发，系统学习如何构建 AI 驱动的 Web 应用。共 7 个模块，建议按顺序推进，每个模块包含理论学习和动手实践。

## 前置要求

- 熟悉 React + TypeScript 基础
- 了解 HTTP 请求、异步编程
- 有一个可用的 AI API Key（OpenAI / DeepSeek / 通义千问等）

## 学习原则

1. **先跑通再优化** — 每个模块先实现最小可用版本
2. **理解数据流** — 重点关注前端与 AI 服务之间的数据交互
3. **动手为主** — 每个知识点都要写代码验证
4. **逐步迭代** — 在前一个模块基础上扩展，最终形成完整应用

## 最终目标

完成全部模块后，你将拥有一个功能完整的 AI 应用，具备：
- 流式聊天对话
- 多轮上下文管理
- 工具调用能力
- 文档知识库问答
- Agent 多步推理展示
