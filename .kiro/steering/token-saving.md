# Token 节省策略

## 避免重复生成

- 已创建的公共组件（Layout、TabBar、InterviewCard）不要重新生成，直接 import 使用
- `src/services/ai.ts` 创建一次后，后续模块只需 import，不要重复封装 fetch 逻辑
- 类型定义如果已存在，直接引用，不要重新定义
- 面试题数据文件只做追加，不要重写整个文件

## 增量开发原则

- 每次只实现用户指定的知识点，不要一次性生成整个模块
- 修改文件时使用精确替换，不要重写整个文件
- 新增面试题时只追加新条目，不要输出已有条目

## 上下文引用

当需要了解已有代码时：
- 先读取目标文件确认当前状态
- 不要假设文件内容，以实际读取结果为准
- 引用已有类型时给出 import 路径即可，不要重复展示类型定义

## 回答精简

- 代码生成后，总结只需说明：创建/修改了哪些文件、实现了什么功能
- 不需要重复解释知识点内容（用户会对照 docs/ 下的文档学习）
- 不需要列出完整的文件内容回顾，除非用户要求
